How to Use This Demo

  1. Click Connect Wallet and select MetaMask.
  2. Click Manipulate Oracle Price and set a crazy value (e.g. 1 or 1,000,000).
  3. Use Buy Tokens to see how your token balance changes.
  4. Use Run Full Attack to automate price manipulation and buying.

The Solidity contracts implement the vulnerable oracle, victim logic, and attacker logic. This web page is just a visual front-end to interact with them using MetaMask and ethers.js.
